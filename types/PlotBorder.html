    PlotBorder: BoxPlotBorder | AxisPlotBorder | ArrowPlotBorder

    A PlotBorder object defines the properties of a plot border.

    The border can be of type "box", "axis", or "arrow". Each type has its own properties. The stroke property defines the color and style of the border. The size property is only applicable for "arrow" type borders and defines the size of the arrow. The overflow property is only applicable for "arrow" type borders and defines how much the arrow can overflow outside the plot area.
